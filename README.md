# static_hurricane_info_site
A quick n dirty site to show such things as what model predicts what intensity: battle of the AI models vs Physics based; as I haul ass down to Mobile Bay to help my dad who has had open heart surgery and won't put down a chainsaw unless I take it.

## What's here

- `index.html`: model-by-model analysis of Hurricane Isaias (AL092026), 12Z 8 Oct 2026 cycle
- `models.html`: key to the hurricane model codes (physics, statistical, AI)
- `methods.html`: data sources, verification method, references
- `tools/`: bash + awk scripts that rebuild every number from NOAA/NHC's public ATCF files
- `data/`: the processed data the pages use

Unofficial analysis, not a forecast. For official forecasts, see https://www.nhc.noaa.gov.
